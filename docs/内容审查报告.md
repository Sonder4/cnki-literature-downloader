# 内容审查报告

## 审查目标

在将本仓库公开发布前，检查是否包含以下不应公开的内容：

- 访问凭证、会话数据与认证信息
- 可识别个人身份的信息
- 特定学校或单位的私有模板依赖
- 本地绝对路径
- 私有项目目录结构与内部工作流痕迹

## 审查范围

- `SKILL.md`
- `agents/openai.yaml`
- `references/`
- `scripts/`
- `README.md`

## 处理结果

已从公开版中移除或泛化以下内容：

1. 本地绝对路径示例
2. 特定学校模板或规范链接
3. 私有 LaTeX 真源和 Word 导出链说明
4. 私有项目目录示例
5. 仅适用于单一论文工程的 profile 名称与输出目录

## 当前结论

本仓库公开版不包含以下内容：

- 可直接使用的访问凭证
- 浏览器会话数据副本
- 账号密码
- 本地用户名路径
- 特定个人身份信息

## 仍需使用者注意

- 运行时依然会使用你本地已登录的浏览器，因此请不要把运行日志、下载目录和浏览器调试输出直接公开。
- 如果你自行扩展 profile、README 或示例数据，请再次检查是否引入个人单位、论文题目或内部路径。
